## US8 — Analyse croisée RAM / disque

### Étapes
Croisement manuel des sorties US6 (`windows.pslist`, journal `Get-WinEvent`) et US7 (`hash-manifest.csv`, `run-keys.reg`) : comparaison PID/chemin/hash entre processus mémoire et fichiers disque.

### Résultats
| Mémoire (US6) | Disque (US7) | Correspondance |
|---|---|---|
| PID 11884 `Res`, actif au dump RAM | `C:\WindSyst\Res.exe`, SHA-256 `49F091AD...E37E1E` | Même hash que l'échantillon original (US2/US3) |
| PID 13648 `Env`, terminé 9s après lancement (WER APPCRASH `Qt5Core.dll` 0x40000015) | `C:\WindSyst\Env.exe` présent | Fichier intact mais exécution avortée avant le code réseau |
| — | `platforms\` vide | Explique le crash observé en mémoire |

Persistance :
```
HKCU\...\Run\Res = C:\WindSyst\Res.exe  →  fichier présent  →  PID 11884 actif en mémoire
HKCU\...\Run\Env = C:\WindSyst\Env.exe  →  fichier présent  →  PID 13648 lancé puis crashé
```
Chaîne registre → disque → mémoire vérifiée : persistance du keylogger fonctionnelle ; module d'exfiltration configuré mais cassé.
